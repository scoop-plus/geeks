Geeks bucket for Scoop

## 食用方法

```powershell
# 使用VCDN
scoop bucket add geeks https://vcdn.qzz.io/scoop/geeks
# 使用Github
scoop bucket add geeks https://github.com/scoop-plus/geeks
```
